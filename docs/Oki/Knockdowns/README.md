# Knockdowns

> This doesn't review the usage of meter 

## Bridal (mid screen)

Bridal main rewards are:

- Simple to route into

- Screen carry
  
- Slightly more damage than other enders

Main downsides are:

- Mixup/oki options are very limited.

- Reward from such mixup/oki is fairly low

## 2D > Shotgun.H

If you are close enough to the opponent, you can do 2D > Shotgun.H to force a knockdown and allow for an IAD j.Pull j.S Safejump, the exact same situation than with Bridal.

[[Video]](https://youtu.be/SeBwbwh9uVk)

## 2D

This is the real deal.

You get more options as oki with better reward.

Opponent doesn't land as far, so distance isn't generally an issue.

Berry makes it makes more threatening for the opponent to take risks.
